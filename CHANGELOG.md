# Changelog

All notable changes to published norm versions are documented here.

## [norms-v0] — 2026-06-11

Initial public release.

- Form A: 22 items (OMIB Set 1), fixed order
- 2PL IRT parameters (`a`, `b`) without answer keys
- Raw score → IQ lookup table (0–22)
- Reference EAP scorer and `verify_result.py` CLI
- Anchored to OMIB calibration (N = 2561), `norms_version: "v0"`

Production IQ Exact uses the same norm version until v1 is released.
